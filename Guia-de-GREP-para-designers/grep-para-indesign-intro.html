O que é GREP?

GREP é uma sigla que significa Global Regular Expression Print. É um programa de busca de texto avançada, que usa padrões de caracteres chamados expressões regulares para encontrar padrões complexos de caracteres em textos. Basicamente um Ctrl+F com esteroides.

Mas talvez seja interessante demonstrar o que é GREP através de demonstrar o que ele não é, comparando-o a uma simples busca de texto. No exemplo abaixo, observe como para encontrar todas as ocorrências que queremos de um certo tipo de dado teríamos que fazer repetidas buscas ou buscar outro caractere que nos levaria para todas as suas ocorrências, de qualquer forma envolvendo trabalho manual. Já a expressão que criamos é flexível suficiente para capturar todas as ocorrências de uma vez:

Tente não focar demais na sintaxe, ela ficará clara em breve!

É útil pensar na busca simples de texto como uma pergunta: para cada palavra neste documento, esta palavra é igual a esta?, enquanto usando expressões regulares estamos perguntando para cada palavra neste documento, esta palavra atende a estes requisitos que eu especifiquei?. São abordagens diferentes, e para a maior parte dos casos uma busca simples de texto será suficiente. É, porém, uma abordagem mais quebradiça, e a força das expressões regulares é revelada justamente quando queremos adicionar certa flexibilidade a esta busca, e atrelá-la aos estilos de caractere.

InDesign, um dos programas mais usados no design gráfico, possui funcionalidades de GREP integradas. Como seu foco é na diagramação de grandes volumes de texto, ter um sistema de busca robusto e flexível é essencial para eficiência e correção de textos, e sua integração com estilos de parágrafo condicionais abre a possibilidades criativas interessantíssimas no âmbito de projeto. E como eu faço para usar o GREP?

É possível usar o GREP dentro do InDesign na aba GREP do menu de busca. Essa é maneira mais simples de dentro de acessar sua funcionalidade dentro um projeto, e é boa para subsitutições de texto rápidas. Você pode digitar sua expressão na caixa de texto, mas caso esqueça a sequência específica de símbolos, o botão com o @ ao lado é um menu que pode ser usado para inserir as expressões manualmente.

Como demonstramos acima, outra maneira mais poderosa de usar o GREP é integrando-o dentro de estilos de parágrafo. Na aba GREP Style é possível criar regras que serão aplicadas dentro daquele estilo de parágrafo, e essas regras são formadas por uma expressão regular e um estilo de caracteres. Toda vez que uma expressão que der match em uma porção de texto dentro deste estilo de parágrafo ele será formatado com o estilo de caracteres especificado.

Dica avançada

Todo sistema macOS vem com GREP pré-instalado no sistema, e pode ser usado de dentro do terminal. O uso de linha de comando infelizmente extrapola o escopo deste guia, mas uma busca rápida dentro de um arquivo de texto seguiria este modelo:

$ grep expressão_de_busca arquivo_de_texto.txt

Porém o uso e potencial desta ferramenta vai muito além deste exemplo simples. Para saber mais, acesse a página de referência.

E se eu quiser saber mais?

O conteúdo deste guia é amplamente inspirado no livro Introdução às expressões regulares, de Michael Fitzgerald. Seu conteúdo parte do pressuposto de que o usuário é mais ou menos familiar com um terminal, então foi adaptado para a realidade do design gráfico.
